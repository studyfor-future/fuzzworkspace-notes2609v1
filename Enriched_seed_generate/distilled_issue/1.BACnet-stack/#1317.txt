Number: 1317

Summarize:
In bacnet-stack v1.5.0, a WriteProperty request that updates OBJECT_STRUCTURED_VIEW / PROP_SUBORDINATE_LIST can trigger a NULL pointer dereference in bacnet_device_object_reference_decode() in src/bacnet/bacdevobjpropref.c, reached from Structured_View_Subordinate_List_Member_Decode() in src/bacnet/basic/object/structured_view.c. The report states that Structured_View_Subordinate_List_Member_Decode() calls bacnet_device_object_reference_decode(apdu, apdu_size, NULL), and bacnet_device_object_reference_decode() later writes to value->deviceIdentifier in the len == 0 branch even when value == NULL. The demonstrated result is an AddressSanitizer-reported segmentation fault and denial of service.

Reproduce:
Use bacnet-stack v1.5.0 with an AddressSanitizer-enabled build of the server application; the report shows the crashing binary as build-gdbasan/server and execution through apps/server/main.c. No explicit build or send commands are provided. Cause the server to process the raw hex PoC inputs exactly as listed under PoC, in sequence (the first begins 81 0b 00 19..., the second begins 81 0a 00 1f...). When the WriteProperty update for OBJECT_STRUCTURED_VIEW / PROP_SUBORDINATE_LIST is handled, AddressSanitizer reports DEADLYSIGNAL with a SEGV caused by a WRITE to 0x000000000000 in bacnet_device_object_reference_decode at src/bacnet/bacdevobjpropref.c:492:38. The stack shown is bacnet_device_object_reference_decode -> Structured_View_Subordinate_List_Member_Decode -> bacnet_array_write -> Structured_View_Write_Property -> Device_Write_Property -> handler_write_property -> apdu_handler -> npdu_handler -> main, and the process aborts.
