IEC 61850 Function and Service Code Reference
=============================================

Important Note
--------------
IEC 61850 does not define one single "Function Code" field like Modbus.

IEC 61850 operations are represented through:

1. MMS PDU types
2. MMS confirmed service tags
3. MMS unconfirmed service tags
4. IEC 61850 ACSI service names
5. GOOSE EtherType and APDU fields
6. Sampled Values EtherType and APDU fields
7. Control model values

For an IEC 61850 function-code corpus, the MMS service tag is the closest
equivalent to a Modbus function code.

    Execute a direct or previously selected control operation.

    Cancel a selected control operation.

    Report final result for enhanced-security control.

GOOSE control block attributes:

GoEna
GoID
DatSet
ConfRev
NdsCom
DstAddress
MinTime
MaxTime
FixedOffs

GOOSE state-number semantics:

stNum
    Incremented when dataset state changes.

sqNum
    Incremented for repeated transmissions of the same state.

confRev
    Changes when dataset/control-block configuration changes.

timeAllowedToLive
    Validity interval expected by subscriber.
