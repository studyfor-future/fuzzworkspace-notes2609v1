issue #543

Description
A Segmentation Fault (SEGV) exists in libiec61850 v1.5.1. A Null Pointer Dereference occurs during a sem_wait call due to the semaphore pointer not being properly initialized or incorrectly set to NULL before use, resulting in a Segmentation Fault. This vulnerability can be triggered by sending a specific message to the server.
