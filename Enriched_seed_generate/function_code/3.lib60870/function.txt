3. IEC 60870-5-104 APCI FRAME TYPES
================================================================

I-format:
    Carries APCI control information and one ASDU.

S-format:
    Carries receive acknowledgement only.

U-format:
    Carries start, stop, or test control function.

I-format first control octet:

bit 0 = 0

Send Sequence Number:
    Stored as sequence number shifted left by one.

S-format first control octet:

0x01

S-format second control octet:

0x00

U-format first control octet:

bit 0 = 1
bit 1 = 1

================================================================
4. IEC 60870-5-104 U-FORMAT FUNCTION CODES
================================================================

STARTDT act:

Control bytes:
0x07 0x00 0x00 0x00

Meaning:
    Start data transfer activation.

STARTDT con:

Control bytes:
0x0B 0x00 0x00 0x00

Meaning:
    Start data transfer confirmation.

STOPDT act:

Control bytes:
0x13 0x00 0x00 0x00

Meaning:
    Stop data transfer activation.

STOPDT con:

Control bytes:
0x23 0x00 0x00 0x00

Meaning:
    Stop data transfer confirmation.

TESTFR act:

Control bytes:
0x43 0x00 0x00 0x00

Meaning:
    Test frame activation.

TESTFR con:

Control bytes:
0x83 0x00 0x00 0x00

Meaning:
    Test frame confirmation.

================================================================
5. IEC 60870-5-104 FRAME START
================================================================

0x68 = IEC 60870-5-104 APDU start byte

APDU format:

Byte 0:
    0x68

Byte 1:
    APDU length

Byte 2-5:
    APCI control field

Byte 6 onward:
    ASDU for I-format only

================================================================
6. IEC 60870-5-101 FRAME START CODES
================================================================

0x10 = Fixed-length frame start
0x68 = Variable-length frame start
0xE5 = Single-character positive acknowledgement

Fixed-length frame ending:

0x16 = End delimiter

Variable-length frame ending:

0x16 = End delimiter

8. COMMON COMMAND QUALIFIER
================================================================

Select/Execute bit:

0 = Execute
1 = Select

Single Command state:

0 = OFF
1 = ON

Double Command state:

0 = Not Permitted
1 = OFF
2 = ON
3 = Not Permitted

Regulating Step Command state:

0 = Not Permitted
1 = Next Step Lower
2 = Next Step Higher
3 = Not Permitted
