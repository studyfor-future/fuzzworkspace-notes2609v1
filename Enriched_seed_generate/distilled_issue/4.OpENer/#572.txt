Number: 572

Summarize:
In OpENer v2.3 / master up to commit 76b95cf, the real TCP explicit-message path on port 44818 (`RegisterSession` / `SendRRData`) can reach `SetAttributeList()` with a default-registered, non-settable `kCipShortString` attribute: Identity class, instance 1, attribute 7 (`product_name`). For non-settable attributes, `SetAttributeList()` still advances over the attacker-supplied value, and for variable-length types it calls `GetCipDataTypeLength(attribute->type, message_router_request->data)` without validating remaining length. For `kCipShortString`, that leads to an unchecked 1-byte read via `GetSintFromMessage()`. With a long padded EPath positioning `message_router_request->data` at the end of the 512-byte stack receive buffer, ASan reports a stack-buffer-overflow / out-of-bounds read. The document states this is at minimum a remote unauthenticated denial of service in the default build.

Reproduce:
Use OpENer v2.3 / master up to commit 76b95cf with the default Ethernet buffer size (`PC_OPENER_ETHERNET_BUFFER_SIZE=512`). Start the server, then run the provided Python 3 PoC in `crash` mode against TCP port 44818 (default host `127.0.0.1`, override with `OPENER_HOST`). The script first sends `RegisterSession`, then `SendRRData` carrying a CIP `SetAttributeList` request to Identity class 1, instance 1, attribute 7. In crash mode it builds a long padded EPath (`build_path(233)`) and sends `attr_count=1`, `attr=7`, with no short-string length byte following the attribute id. Expected result: ASan reports a stack-buffer-overflow / out-of-bounds read when `SetAttributeList()` skips the non-settable short string value.
