Summarize:
lib60870 2.3.6 CS104 server-side code reportedly has a heap-buffer-overflow when it processes the supplied PoC byte stream. The crash is in HighPriorityASDUQueue_hasUnconfirmedIMessages(), on the path handleMessage() -> MasterConnection_hasUnconfirmedMessages() -> HighPriorityASDUQueue_hasUnconfirmedIMessages(). The reporter's debugging suggests a format mismatch in the high-priority ASDU queue: HighPriorityASDUQueue_enqueue() stores a uint16_t msgSize followed by encoded ASDU bytes, while HighPriorityASDUQueue_hasUnconfirmedIMessages() later traverses the queue as if entries begin with struct sMessageQueueEntryInfo. In that analysis, ASDU payload bytes are misinterpreted as queue metadata, a bogus entryInfo.size moves traversal past lastEntry, and reading continues into non-entry data until an out-of-bounds read occurs. The observed result is an AddressSanitizer heap-buffer-overflow.
