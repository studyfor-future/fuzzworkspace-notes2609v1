issue #196

Summary
I found a heap-buffer-overflow in the CS104 server-side code of lib60870 2.3.6.

The crash occurs in:

HighPriorityASDUQueue_hasUnconfirmedIMessages()
and is reached through the server-side path:

handleMessage()
MasterConnection_hasUnconfirmedMessages()
HighPriorityASDUQueue_hasUnconfirmedIMessages()
Based on debugging, the root cause appears to be a format mismatch in the high-priority ASDU queue:

HighPriorityASDUQueue_enqueue() stores entries as:
uint16_t msgSize
followed by encoded ASDU bytes
HighPriorityASDUQueue_hasUnconfirmedIMessages() later traverses the same queue as if each entry begins with a struct sMessageQueueEntryInfo
As a result, serialized ASDU payload bytes are later misinterpreted as queue-entry metadata. This can produce a bogus entryInfo.size, causing queue traversal to skip past lastEntry and continue reading non-entry data until an out-of-bounds read occurs.
