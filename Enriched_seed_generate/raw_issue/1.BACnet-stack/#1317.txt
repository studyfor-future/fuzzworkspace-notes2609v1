issue #1317

Summary

A NULL pointer dereference can be triggered in bacnet_device_object_reference_decode() when a WriteProperty request updates OBJECT_STRUCTURED_VIEW / PROP_SUBORDINATE_LIST in bacnet-stack v1.5.0.

The crash occurs because Structured_View_Subordinate_List_Member_Decode() calls:

bacnet_device_object_reference_decode(apdu, apdu_size, NULL);
and bacnet_device_object_reference_decode() later writes to value->deviceIdentifier in the len == 0 branch even when value == NULL.

This results in a segmentation fault / denial of service.

Affected version: v1.5.0
