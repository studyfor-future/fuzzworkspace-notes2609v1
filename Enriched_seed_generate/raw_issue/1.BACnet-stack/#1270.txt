issue #1270

Description:
A malformed UCOV / property-value payload can cause bacapp_decode_application_data() to accept an oversized extended application length without verifying it against the remaining APDU bytes. The oversized length is propagated through bacapp_decode_data() into host_n_port_decode(), which trusts the size and eventually triggers an invalid read in bacnet_tag_number_decode(), causing a crash.

Version: v1.3.1
